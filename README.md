# AORA Apps

Apps and tools for the Australian Offroad Academy.

## AORA Tides

Static page for Saturday tide predictions on K’gari (Fraser Island) 75 Mile Beach for 2027.

- Source: `tides/index.html`
- Original preview: https://moss-cinder-star-zest.grok.me/

To publish via GitHub Pages:
1. Go to repo Settings → Pages
2. Source: Deploy from a branch
3. Branch: main, folder: /tides (or root if you move the file)

Once enabled, it will be available at `https://aora73.github.io/AORA-Apps/tides/` (or similar).
